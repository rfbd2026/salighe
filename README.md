# دلت چی می‌خواد؟

- `docs/index.html`  → سایت عمومی (GitHub Pages از پوشه‌ی `/docs` سرو می‌شود)
- `admin/admin.html` → پنل مدیریت. **منتشر نمی‌شود**؛ فقط از روی کامپیوتر خودت باز کن.
- `sql/`             → به ترتیب `01`, `02`, `03` در Supabase SQL Editor اجرا شوند.

قبل از اجرای `02-admin.sql` ایمیل `YOUR-EMAIL@example.com` را با ایمیل ادمین عوض کن (در خود Supabase، نه در گیت).
هرگز کلید `service_role` را در هیچ فایلی نگذار.
